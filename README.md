## 🚀 Key Features

1. **Light & Dark Mode**:
   - Persistent theme toggle button on the navigation bar.
   - Smooth transitions with Tailwind CSS `class` strategy and custom CSS.
   - Interactive 3D elements dynamically adapt shaders to light/dark themes.

2. **3D Interactive Elements**:
   - **Three.js Hero Canvas**: Interactive glowing tech crystal polyhedron with orbiting rings and floating particles reacting to cursor movement.
   - **3D Card Hover Perspective**: Cards dynamically tilt and scale on mouse movement.

3. **Multi-Role Portals & Authentication**:
   - **Student Portal** (`/student/`): Course classroom, video player, lesson notes, assignment submissions, payment history, and verified digital certificates.
   - **Teacher Portal** (`/teacher/`): Module & lesson management, assignment creation, student grading, and feedback.
   - **Admin Panel** (`/admin/`): Revenue analytics, course management, payment approval (bKash/Nagad/Rocket verification), user management, and campus settings.

4. **Payment Gateways & Invoicing**:
   - **bKash**: Personal/Merchant Send Money (`01812669757`)
   - **Nagad**: Personal Send Money (`01817122483`)
   - **Rocket**: Send Money (`01812669757-9`)
   - **Bank Transfer**: Islami Bank Bangladesh Ltd, Feni Branch
   - **Instant Sandbox Mode**: One-click instant approval for demo/testing.
   - **Discount Coupons**: Supports `UTC50` (50% off) & `UTC30` (30% off).
   - **Printable Money Receipts / Invoices**: Branded PDF/Printable receipts.

5. **Self-Initializing SQLite Database**:
   - SQLite PDO database stored at `db/utc_elearning.sqlite`.
   - Automatically initializes schema and seeds all 10 courses, default admin, teachers, and student accounts.
